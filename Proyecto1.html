De la Teoría a la Práctica

Walkthrough detallado de pentesting sobre la máquina vulnerable digitalworld.local: snakeoil. Un análisis profundo de vulnerabilidades web y escalamiento de privilegios.

Metodología de Ataque

1. ¿Qué se hizo? (Reconocimiento y Fuzzing)

Se desplegó un entorno aislado para analizar la máquina objetivo. Se utilizó Nmap para identificar servicios en los puertos 22 (SSH) y 8080 (HTTP). Posteriormente, mediante Gobuster, se descubrieron endpoints ocultos de una API (login y registration) que no estaban expuestos al usuario.

2. ¿Por qué funcionó? (Explotación Web)

La API presentaba una mala gestión de métodos HTTP. Al interceptar el tráfico con Burp Suite y forzar un método POST en lugar de GET, se logró saltar las validaciones. Esto permitió crear un usuario ilícito, autenticarse y recibir un token de sesión criptográfico (JWT).

3. ¿Cómo se obtuvo el control? (Escalamiento)

Se realizó una Inyección de Comandos (OS Command Injection) explotando la falta de sanitización al enviar la entrada de red hacia el comando curl del sistema, revelando las credenciales de SSH. Finalmente, se abusó de una configuración permisiva en el archivo Sudoers para ejecutar comandos sin contraseña, logrando acceso Root.
