File Path Traversal: Validation of file extension with null byte bypass

Evasión de validación de extensión obligatoria mediante la inyección de un byte nulo codificado (%00) para truncar la lectura de la ruta en el sistema de archivos.

1. Ficha Técnica del Laboratorio

Nombre del Laboratorio

Validation of file extension with null byte bypass

Nivel de Dificultad

Practitioner

Tipo de Explotación

File Path Traversal (Null Byte Injection / Extension Bypass)

Objetivo del Laboratorio

Evadir la validación de extensión .jpg mediante un byte nulo (%00) para extraer el archivo /etc/passwd.

2. Explicación Técnica de la Vulnerabilidad

Para restringir el acceso a recursos no autorizados, algunas aplicaciones verifican que el nombre del archivo proporcionado por el usuario concluya con una extensión específica permitida (como .jpg o .png). La vulnerabilidad de Null Byte Bypass surge por una asimetría en el manejo de cadenas entre el lenguaje de alto nivel de la aplicación web y las bibliotecas de bajo nivel del sistema operativo (escritas en C/C++).

Mientras el lenguaje de alto nivel trata la cadena completa como un objeto de longitud definida y valida satisfactoriamente el sufijo .jpg, las llamadas al sistema operativo interpretan el carácter nulo (0x00 o %00 en URL) como un terminador de cadena (Null Terminator), ignorando todo lo que se encuentre a su derecha. Dentro de OWASP Top 10 (A01: Broken Access Control / A03: Injection), este fallo compromete críticamente la Confidencialidad en la tríada CIA, permitiendo exfiltrar archivos del sistema operativo, código fuente o archivos de configuración con credenciales de bases de datos sin importar su extensión real.

3. Procedimiento Paso a Paso

Secuencia técnica de intercepción, inyección de byte nulo y análisis de respuesta mediante Burp Suite.

1

Intercepción de la Petición de Imagen

Se inicia el laboratorio en el navegador integrado de Burp Suite. En la pestaña Proxy > HTTP history, se filtran los recursos tipo imagen y se localiza la petición GET hacia el endpoint vulnerable /image?filename=31.jpg, la cual se envía al módulo Repeater (Ctrl + R).

2

Verificación del Filtro de Extensión

En el Repeater se intenta inyectar el vector tradicional ../../../etc/passwd. El servidor rechaza la petición con un error 400 Bad Request ("No such file") debido a que el validador del backend exige estrictamente que el parámetro filename termine con la extensión .jpg.

3

Inyección del Payload con Null Byte (%00)

Para satisfacer la validación del sufijo y al mismo tiempo truncar la ruta al abrir el archivo en el sistema operativo, se inserta un byte nulo codificado en URL (%00) antes de la extensión requerida: filename=../../../etc/passwd%00.jpg.

4

Truncamiento de Extensión y Resolución

El filtro de alto nivel verifica que la cadena termina en .jpg y autoriza la operación. Al llegar al sistema de archivos subyacente, la lectura se detiene en el byte nulo %00, ignorando la extensión y retornando un estado HTTP/2 200 OK con el contenido de /etc/passwd, completando el laboratorio.

5. Explicación del Payload

../../../etc/passwd%00.jpg

El payload explota la diferencia en la representación de cadenas entre el entorno de ejecución web y las funciones nativas del sistema operativo:

1. Validación App: Termina en ".jpg" → Válido
2. Inyección Null: %00 actúa como fin de cadena (\0)
3. Lectura en SO: ../../../etc/passwd.jpg

6. Mitigación Recomendada

Confiar únicamente en la validación de la extensión del archivo no impide el escalado de directorios ni la inyección de caracteres de control:

  • Rechazar Bytes Nulos y Caracteres de Control: Filtrar o bloquear de forma inmediata cualquier entrada que contenga bytes nulos (\0 o %00) y mantener actualizados los entornos de ejecución (versiones modernas de PHP y Java detectan bytes nulos en rutas de archivos).
  • Validación por Lista Blanca y Canonicalización: Verificar el nombre del archivo contra una lista blanca estricta de caracteres alfanuméricos y comprobar mediante getCanonicalPath() que el archivo resida dentro de /var/www/images/.
