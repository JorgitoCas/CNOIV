Laboratorio 07

File Path Traversal

Resolución práctica y análisis de vulnerabilidad de salto de directorio mediante Burp Suite.

Contexto de la Práctica

El presente documento adjunta de qué manera se puede usar herramientas como el Burp Suite con la intención de vulnerar una debilidad en sitios web[cite: 5]. En este caso usaremos el Path File Traversal, lo cual significa usar la falta de validación para ejecutar comandos que nos puedan retornar valores como contraseñas o cuentas[cite: 5].

Metodología de Explotación

1

Intercepción Inicial

Se inicia el Burp Suite y se accede al link de la práctica, además que se le da adelante por primera vez para cargar el sitio[cite: 5]. Esto nos permite ver las primeras consultas que genera[cite: 5]. Al cargar las imágenes nos permite ver que las está tomando desde alguna carpeta[cite: 5]. Es importante verificar que nos está pidiendo obtener los contenidos de /etc/password[cite: 5].

2

Análisis de Respuesta

Ahora tomamos una de estas request de imagen para ver cómo es que interactúa[cite: 5]. Al ver cómo interactúa nos damos cuenta que en efecto está retornando la imagen[cite: 5]. Así que intentaremos darle otras instrucciones a ver cómo reacciona[cite: 5]. Para esto es importante entender que solo se podrán ver los archivos a los cuales la cuenta de la app tenga permisos[cite: 5].

3

Inyección del Payload

Intentamos empezar la vulneración, primero verificaremos si acepta la ruta absoluta[cite: 5]. Nos contesta que no encuentra o no existe etc/passwd debido a que estamos dentro del folder de imágenes[cite: 5]. Como no sabemos en qué nivel estamos, probamos retroceder agregando directorios con un back, y en este caso con 4 niveles (../../../../) lo logramos[cite: 5].
